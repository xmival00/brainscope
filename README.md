# brainscope

Desktop app for coregistering a CT to an MRI and localizing the contacts of intracranial leads, for humans and
pigs. NIfTI or DICOM in; contact coordinates in the MRI space out, as a BIDS-compatible CSV.

**Research use only. Not for clinical decisions.**

Status: planning, no code yet. See [docs/PLAN.md](docs/PLAN.md).
